Career Engine

Laravel · PostgreSQL · pgvector · Claude API · Chrome extension

Context

A career workflow application designed to help users capture job descriptions, organize applications, and prepare tailored application materials with AI assistance and human approval.

Product and technical approach

  • Laravel application with PostgreSQL as the primary data store.
  • Chrome extension concept for capturing job descriptions from job platforms.
  • Claude API workflows for drafting cover letters and application answers.
  • Structured writing preferences and retrieval using pgvector.
  • Approval steps so generated content is reviewed before use.
  • Bounded prompts and confidence thresholds to keep AI output controlled.

Engineering considerations

The product is designed around a human-in-the-loop workflow. AI assists with repetitive drafting, while the user retains control over final content. Structured preferences and retrieval help maintain consistency across applications.

Outcome: An ongoing product build exploring practical AI integration, retrieval-informed personalization, and approval-based workflows.
