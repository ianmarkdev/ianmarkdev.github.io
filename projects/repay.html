REPAY

Ruby on Rails · MySQL · Sidekiq · Heroku · REST APIs

Context

REPAY provides payment-processing systems for partner banks, supporting mortgage payments, ACH, checks, and other payment methods. Several core applications were running on an outdated Rails version.

My contribution

  • Developed B2B payment-processing systems for partner banks.
  • Migrated 4–6 core legacy Ruby on Rails applications from Rails 3 to Rails 6.
  • Developed shared Ruby gems for authentication and ACH payment-gateway functionality.

Engineering considerations

Pulling authentication and payment-gateway logic into shared gems gave many applications one tested implementation, instead of each maintaining its own copy of security-sensitive code.

Outcome: The shared gems were adopted by 12–15 applications across the company.
