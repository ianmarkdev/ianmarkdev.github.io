LawDictate

Next.js 16 · TypeScript · Tailwind CSS · Firebase · Firestore · Cloud Functions · FCM · Vitest · Playwright

Context

A browser-based dictation and transcription workflow for an Australian law firm. The product needed to support audio capture, file handling, notifications, and distinct responsibilities for authors, typists, and administrators.

My contribution

  • Developed the application using Next.js and TypeScript.
  • Implemented Firebase Authentication and role-aware application workflows.
  • Worked on browser audio recording, IndexedDB storage, and Firebase Storage integration.
  • Implemented notification workflows using Firebase Cloud Messaging and Cloud Functions.
  • Integrated browser hardware support for foot pedals using WebHID/WebUSB.
  • Implemented Firestore access controls and application security rules.
  • Added automated testing with Vitest and Playwright.
  • Used AI-assisted workflows for design exploration, mockups, implementation, and development tasks.

Engineering considerations

The application combines browser capabilities, cloud services, and role-based workflows. Careful handling of audio data, authorization rules, and end-to-end testing are important to keeping the experience dependable.

Outcome: Delivered a functional full-stack application covering core dictation workflows, user permissions, audio handling, notifications, and automated testing.
